# ESS 배터리 수명 예측

처음 100번의 충방전 기록만으로 배터리의 총 수명(cycle_life)을 예측한다.
배터리 교체 비용은 ESS 설치비의 30~40%다. 수명을 미리 알면 교체 시점과 예산을 계획할 수 있다(예지보전).

## 프로젝트 개요
- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12) / 평가 데이터 : Batch 2 (2018-02-20)
- 태스크 : **Regression** (cycle_life 예측)
  - 분류(550 기준)를 고르지 않은 이유 : 단수명 배터리가 학습 데이터에 1개, 테스트 데이터에 30개라 학습할 수 없다.
- DAY 1 보고서(EDA와 모델 설계 전략) : [docs/DS-MINI-Design-울산_1반-김해린.pdf](docs/DS-MINI-Design-울산_1반-김해린.pdf)

## 데이터 정리
- 정답(수명)을 믿을 수 없는 배터리 20개를 뺐다 (139개 → 119개).
  - 수명 값이 없는 10개 (Batch 2 특수 충전 실험 8개, Batch 3 실험 종료까지 수명 미도달 2개)
  - 수명이 끝나기 전에 실험이 멈춘 10개 (Batch 1, 마지막 용량이 수명 끝 기준 0.88Ah보다 높음)
- 최종 : 학습 Batch 1 36개 / 테스트 Batch 2 39개

## EDA
- **Cycle Life 분포** — 테스트(Batch 2)는 72%가 수명 500 미만이지만, 학습(Batch 1)의 최소 수명은 534다.
- **열화 곡선** — 급격히 꺾이는 지점(Knee)은 모두 100번째 사이클 이후라, 처음 100번의 용량 값만으로는 수명을 구분할 수 없다.
- **ΔQ(V) 곡선** — 100번째와 10번째 방전 곡선 차이의 분산(log)이 수명(log)과 가장 강하게 관련된다(상관계수 −0.90). 단, Batch 2는 같은 ΔQ 값에서 수명이 더 짧다.
- **충전 속도** — 빠를수록 수명이 짧은 경향은 Batch 1 안에서만 나타난다(−0.58 → 전체 −0.10).
- **상관관계** — 배치가 바뀌어도 수명과 관련이 유지되는 피처는 ΔQ 계열뿐이다. 서로 겹치는 피처가 많아 묶음마다 1개만 쓴다.

> 정정 : DAY 1 보고서 Q5의 "전체 배치" 상관계수는 내부 저항(IR)이 측정되지 않은 Batch 2 배터리 6개가 빠진 113개 기준이었다. 119개로 다시 계산해도 차이는 최대 0.05이며 결론은 같다.

## Modeling

### 피처 엔지니어링 전략
- 핵심 피처 : **ΔQ 분산(log)** 1개
- 보조 후보 3개(용량 감소 기울기, 평균 충전 속도, 평균 온도)를 하나씩 추가해 봤지만, 모두 CV 오차가 나빠져 채택하지 않았다. EDA의 "Batch 1에서만 통하는 신호"라는 판단과 일치한다.

### 데이터 분할
- Train 27개 / Valid 9개 (Batch 1, 수명 3구간 층화) / Test 39개 (Batch 2, 마지막에 1번만)
- Train CV는 같은 충전 방식의 배터리를 같은 묶음에 넣었다(누수 방지). 표준화 기준은 학습 데이터로만 정했다.

### 실험 이력
| 실험 | 피처 | Train CV MAPE | Valid MAPE |
|---|---|---|---|
| **E1 선형 회귀 (최종)** | **dq_logvar** | **10.5** | **7.1** |
| E2 + 용량 감소 기울기 | 2개 | 13.5 | 6.9 |
| E2 + 평균 충전 속도 | 2개 | 11.0 | 7.8 |
| E2 + 평균 온도 | 2개 | 11.0 | 7.1 |
| E3 Ridge | 4개 | 12.5 | 9.0 |
| E4 Lasso | 4개 | 11.6 | 8.1 |
| E5 RandomForest | 4개 | 13.2 | 7.2 |

### 모델 선택 및 근거
- 최종 모델 : **선형 회귀 (dq_logvar 1개, 타깃 log10 수명)**
  - Train CV 오차가 가장 낮고, 가장 단순해 학습 데이터 36개에 과적합될 위험이 가장 작다.
  - 학습 데이터에서 직선 관계 가정이 성립함을 잔차로 확인했다(02_modeling Step 4-1).
  - 트리 모델은 학습 최대 수명(1,074)을 넘는 값을 예측할 수 없다.
- Lasso도 dq_logvar를 중심으로 쓰고 나머지 피처는 0이나 매우 작게 만들었다. ElasticNet은 Ridge·Lasso가 모두 기준선보다 나빠 생략했다.
- 모델 선택이 끝난 뒤, 최종 모델은 Batch 1 전체(36개)로 다시 학습하고 Batch 2를 한 번만 예측했다. (Train·Valid 점수는 학습 27개로 학습한 모델, Test 점수는 36개로 다시 학습한 모델의 결과다.)

## 성능 결과
| 구분 | MAPE (%) | 비고 |
|---|---|---|
| Train (Batch 1 CV) | 10.5 | |
| Valid (Batch 1 Hold-out) | 7.1 | |
| Test (Batch 2) | 28.6 | RMSE 163 사이클, R² 0.45 |
| Gap (Train-Valid) | −3.4 | 과적합 없음 |
| Gap (Valid-Test) | +21.5 | 배치 간 일반화 저하 |
| Gap (Target-Test) | +19.5 | Target : 원논문 9.1% |

- Gap(Train–Valid)은 Valid − Train으로 계산했다(MAPE는 낮을수록 좋으므로 (+)가 과적합을 뜻하도록).
- **과적합은 없다.** Valid가 더 좋은 것은 검증용이 9개뿐이고 그중 4개는 같은 충전 방식의 짝이 학습 데이터에 있었기 때문이다. 실력은 Train CV 10.5%가 더 현실적이다.
- **Test 오차는 거의 전부 한 방향이다.** MAPE 28.6%와 평균 오차 방향 +28.1%가 거의 같고, 39개 중 38개를 실제보다 길게 예측했다. Batch 2는 같은 ΔQ 값에서 수명이 더 짧기 때문이며, DAY 1 EDA(Q3)에서 예상한 위험이다.

## 오류 분석
- **공통점** : 크게 틀린 배터리는 수명이 짧다 (500 미만 평균 +31.9%, 800 이상은 +9.1%로 원논문 수준).
- **원인 가설** : 학습 데이터의 최소 수명은 534로, 400대 배터리를 학습한 적이 없다. 같은 ΔQ 값이어도 Batch 2의 짧은 배터리는 훨씬 빨리 수명이 끝난다.
- **기각한 가설** : Batch 2에만 있는 "2단계가 더 빠른 충전 방식"은 원인이 아니었다 (해당 8개 +29.4% vs 나머지 +27.8%).
- **개선 방향** : 여러 배치를 함께 학습해 짧은 수명 배터리를 포함하고, 배치 간 차이를 보정할 피처를 찾는다.
- 자세한 내용 : 02_modeling Step 5~6

## ESS 도메인 해석
- **활용** : 수명이 긴 배터리(800 이상)는 오차 약 9%로, 교체 시점과 예산을 대략 계획하는 데 쓸 수 있다.
- **한계** : 수명이 짧은 배터리는 실제보다 길게 예측되어, 그대로 쓰면 교체가 늦어질 위험이 있다. 불량 조기 선별에는 아직 쓰기 어렵다. 학습 데이터가 한 배치 36개뿐이다.
- **실제 배포에 필요한 것** : 여러 생산 배치로 학습하고, 새 배치마다 성능을 점검한다. 예측이 길게 쏠리는지 감시하다가(데이터 드리프트) 정해진 주기나 성능 하락 시 다시 학습한다. 예측값 하나보다 수명 범위를 함께 제시한다.
